# AI Sathi — Your Smart AI Toolkit

A mobile-friendly Hindi + English starter website with four writing tools:
- AI Writer
- YouTube Script Generator
- Instagram Caption Generator
- Bio Generator

## Run locally
Open `index.html` in a browser.

## Current status
This is a front-end demo. Drafts are generated from local templates; no live AI model or API is connected yet. Do not describe the current version as a live AI service.

## Next steps
1. Connect a secure backend and a real AI provider. Keep API keys on the server, never in browser JavaScript.
2. Add input validation, rate limits, and clear usage limits.
3. Test on Android screen sizes and accessibility.
4. Deploy the static front end (for example, Cloudflare Pages).
5. Add a privacy policy and terms before collecting user data or monetizing.

## Deployment
Connect this repository to Cloudflare Pages and use the repository root as the build directory. No build command is needed for this plain HTML version.
